# Task Tracker CLI

Консольное приложение для управления задачами на Java.

## Возможности

- добавление задач;
- просмотр всех задач;
- фильтрация выполненных и невыполненных задач;
- поиск задач;
- установка дедлайна;
- отметка задачи как выполненной;
- удаление задач;
- сохранение задач между запусками.

## Команды

| Команда | Описание |
|---|---|
| `add` | Добавить задачу |
| `list` | Показать все задачи |
| `list_active` | Показать только невыполненные задачи |
| `list_done` | Показать только выполненные задачи |
| `list_overdue` | Показать просроченные задачи |
| `done` | Отметить задачу как выполненную |
| `delete` | Удалить задачу |
| `search` | Найти задачи, содержащие слово (без учёта регистра) |
| `set_deadline` | Установить дедлайн задачи |
| `help` | Показать список команд |
| `exit` | Выйти из приложения |

## Формат дедлайна

Дедлайн вводится в формате:

```text
dd.MM.yyyy HH:mm
```

Например:

```text
01.11.2026 00:00
```

## Пример использования

```text
> add
Enter task description:
Buy milk

> list
1. Buy milk

> done
Enter task id:
1

> list_done
1. Buy milk [DONE]

> exit
```

## Хранение данных

Задачи сохраняются в файл `memory.dat`, поэтому данные не теряются после завершения программы.

## Запуск

Склонируйте репозиторий:

```bash
git clone https://github.com/Sakoan-ui/taskTrackerCLI.git
```

Перейдите в директорию проекта:

```bash
cd taskTrackerCLI
```

После этого запустите приложение из IntelliJ IDEA или через Maven.
